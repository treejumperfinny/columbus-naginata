## Tech stack

- HTML
- CSS
- JavaScript
- Google Fonts
- Unsplash

## Run locally

From this directory, start a local web server:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.

Stop the server with `Ctrl+C` when you are finished.

Alternatively, open `index.html` directly in a browser. A local server is recommended for the most consistent behavior.
